# PosterX

Next.js 15 + Supabase architecture scaffold for a 3D-first poster e-commerce storefront.

## Included

- App Router with strict TypeScript setup.
- Suspense-based product loading + skeleton states.
- R3F hero scene with mouse parallax.
- Lenis smooth scrolling provider.
- Server Action checkout computation with COD fee logic.
- Supabase SQL migration with Products, Variants, Orders, and RLS.
- Supabase Edge Function for order confirmation trigger.
- Dynamic product OpenGraph image endpoint.

## Quick start

```bash
npm install
npm run dev
```
